# Регламент ежедневной генерации · ONNO AI Academy

Этот файл читает сессия, которая просыпается **каждый день в 04:00 по Ташкенту (23:00 UTC)**.
Человека рядом нет. Всё, что здесь написано, исполняется без вопросов и без вкусовых решений.

Порядок шагов менять нельзя. Шаг 2 обязан отработать до шага 5 — иначе можно молча слить баланс.

## 1. Выбрать тему дня

Взять **местную** дату в Ташкенте. `D` — число полных суток от эпохи `2026-01-01` (в этот день
`D = 0`).

```
index = (D mod 30) + 1
```

Проверка: `2026-08-16` → `D = 227` → `227 mod 30 = 17` → тема **18**.

Открыть `TOPICS.md`, взять тему с этим номером. Никакого выбора «по настроению». Правило
детерминированное и не хранит состояния: две сессии в один день дадут одну тему.

Если в `runs/` уже лежит файл за сегодняшнюю дату со статусом `shipped` — работа сделана.
Выйти молча, ничего не генерировать.

## 2. Преflight: анлим и баланс

**2.1. Проверить, не появился ли анлим у 2.5.** На момент постановки задачи ONNO отвечал на
`use_unlim: true` для `seedance_2_5` ошибкой `Unlimited generations aren't supported for
seedance_2_5`. Это ограничение платформы, а не настройка. Оно может измениться, поэтому
проверяется каждый день:

```
models_explore(action='list', type='video', unlim=true)
```

- `seedance_2_5` есть в списке **и** `unlim.available == true` → добавить `use_unlim: true`.
  Записать `billing: unlim`.
- Иначе — `use_unlim` **не передавать вовсе** (ключа нет на карточке модели, лишний ключ ловит
  отказ). Платить кредитами, записать `billing: credits`.

Модель не менять ни при каком исходе. Seedance 2.5 выбран владельцем осознанно и дважды.

**2.2. Баланс.** `balance()`, затем `generate_video` с `get_cost: true` на сегодняшних
параметрах — заявка не отправляется, деньги не списываются.

- `credits < 2 × cost` → **не генерировать**. `status: blocked`, причина `insufficient_credits`,
  уведомить владельца. Порог именно двойной: бюджет дня — две генерации.
- `credits < 7 × cost` → генерировать, но первой строкой уведомления написать остаток топлива.

Ориентир на 1080p / bitrate high: **9 кредитов за секунду**, то есть 135 за 15-секундный ролик.
Считать всегда через `get_cost` — тариф может измениться.

## 3. Собрать промпт

1. Взять `PROMPT-MASTER.txt` целиком.
2. Удалить верхний блок `FILL RULES` вместе со строкой-разделителем `———`. Промпт начинается со
   слов `HORIZONTAL 16:9`.
3. Подставить десять слотов сегодняшней темы из `TOPICS.md` **побайтово**. Эта сессия ничего не
   сочиняет, не пересказывает и не переставляет.
4. Всё остальное — тоже побайтово. Ни одной правки вне слотов.

Если у темы не хватает хотя бы одного слота или он пуст — **не выдумывать и не брать соседнюю
тему**: подмена рассинхронизирует тридцатидневную ротацию с днём года, и позже два дня выдадут
один и тот же фильм. `status: blocked`, причина `topic_incomplete`, уведомить, не генерировать.

Лицо, возраст, черты — **не описывать никогда**. Описание поверх фотографии борется с самой
фотографией. Разрешено фиксировать только волосы, гардероб, позу и действие — они уже
зафиксированы в мастер-промпте.

## 4. PRE-SUBMIT PROMPT ASSERT

Единственная проверка **до** списания денег. Полный текст — пункт 1 в `ACCEPTANCE.md`. Коротко:

- в собранной строке нет `{{`, `}}`, `FILL RULES`, `DELETE THIS BLOCK`, `———`;
- ровно один раз встречается `<<<abd99f1e-d482-4cf5-92a4-2ce3aea26018>>>`;
- строка начинается с `HORIZONTAL 16:9`;
- присутствуют все блоки: `CHARACTER — HAIR — WARDROBE — THE ROOM — CAMERA — STAGING —
  THE APPARATUS — TIMELINE — LIGHT — STYLE — AUDIO — NEGATIVE —`;
- в `params` ровно восемь ключей и ни одного лишнего; `aspect_ratio` — литерал `"16:9"`,
  никогда `auto`;
- `medias` не пуст **с первой попытки**.

Любой провал — отмена запуска, ничего не отправляется.

## 5. Генерация

Параметры — ровно из `PARAMS.json`. Перед отправкой дополнить `medias`: вызвать
`show_reference_elements` на `abd99f1e-d482-4cf5-92a4-2ce3aea26018` (бесплатно, read-only) и
добавить все возвращённые image-медиа как дополнительные `{role: "image_references"}`, пропуская
дубли. Если вызов не удался — отправлять `PARAMS.json` как есть и записать
`elements_lookup: unavailable`.

Вызвать `generate_video`, дождаться результата через `jobs_wait`. Виджеты не открывать,
`show_generations` не звать — смотреть некому.

## 6. Приёмка и бюджет перегенерации

**Бюджет жёсткий: две генерации за сутки, включая первую. Третьей не бывает никогда.**

Порядок: сначала `ASSET EXISTS` (пункт 3 в `ACCEPTANCE.md`), потом всё остальное. Проверки
разделены на два класса:

- **RE-ROLL class** — `ASSET EXISTS (b)`, `DURATION`, `AUDIO PRESENT`, `NO SPEECH`,
  `SINGLE CONTINUOUS TAKE`, `THE DELTA HAPPENED`. Провал → одна перегенерация тем же промптом.
- **LOG-ONLY** — всё остальное. Результат с измеренным числом пишется в журнал, ролик уходит.

Упавшая джоба (`status: failed`) — **не повод для перегенерации**: промпт тут ни при чём.
Записать ошибку дословно, уведомить, остановиться.

Если вторая генерация тоже валит проверку RE-ROLL класса — `status: shipped-with-defects`,
перечислить провалы в журнале и в уведомлении, остановиться.

## 7. Журнал и пуш

Создать `runs/YYYY-MM-DD.md`:

```markdown
---
date: 2026-08-16
day_index: 18
topic: "Финал без развязки"
model: seedance_2_5
billing: credits            # credits | unlim
injection: media-only       # media-only | both | n/a
generations: 1              # 1 или 2
credits_spent: 135
credits_left: 6467
status: shipped             # shipped | shipped-with-defects | blocked | failed
job_id: ...
url: https://...
---

Результаты всех проверок с измеренными числами. Что провалилось и в каком классе.
```

Закоммитить и запушить в ветку `claude/onno-ai-academy-video-gen-i17ggk`
(`git push -u origin claude/onno-ai-academy-video-gen-i17ggk`). При сетевой ошибке — до четырёх
повторов с задержками 2с / 4с / 8с / 16с.

Журнал — это память задачи. Сессия каждый день новая; чего нет в `runs/`, того не было.

## 8. Уведомление

Одно сообщение: тема дня, ссылка на ролик, чем платили, сколько кредитов осталось. Если статус
не `shipped` — первой строкой причина. Длинных отчётов не писать.

## 9. Отказы

| Что случилось | Что делать |
|---|---|
| Ошибка авторизации / воркспейс не выбран | `select_workspace` на воркспейс из раздела 0, повторить один раз |
| `Unlimited generations aren't supported` | Ожидаемо. Убрать `use_unlim`, платить кредитами |
| Кредитов меньше двух генераций | `status: blocked`, уведомить, модель не менять |
| В эхе промпта остался `<<<abd99f1e` | Ожидаемо и **не** ошибка: лицо пришло из `medias`. Записать `injection: media-only` |
| Джоба висит дольше 20 минут | `status: failed`, причина `timeout`, уведомить |
| Файлов регламента нет в рабочей копии | Ветка не выкачана: `git fetch origin claude/onno-ai-academy-video-gen-i17ggk`, затем `git checkout` на неё |
| Файл за сегодня уже `shipped` | Выйти молча |

Чего нельзя ни при каких обстоятельствах: менять модель, снимать identity-lock, описывать лицо
словами, генерировать больше двух раз за сутки, подменять тему дня, пушить в чужую ветку.
