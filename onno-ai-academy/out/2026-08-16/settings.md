# Настройки ONNO web UI — «Один предмет»

Вставить `prompt.txt` целиком в поле промпта и выставить:

| Поле | Значение |
|---|---|
| Модель | **Seedance 2.5** |
| Режим | **Unlimited** |
| Референс / персонаж | элемент **Javokhir** |
| Соотношение сторон | **9:16** |
| Разрешение | **1080p** |
| Длительность | **10 с** |
| Аудио | **включено** |
| Битрейт | **high**, если поле есть |

**Про референс.** В промпте уже стоит токен `<<<abd99f1e-d482-4cf5-92a4-2ce3aea26018>>>`. Если веб-интерфейс
разрешает токен сам — не трогать ничего. Если нет — прикрепить элемент «Javokhir» через интерфейс и удалить
токен из вставленного текста. Лицо приходит только из элемента: в промпте нет ни одного слова о внешности,
и дописывать их нельзя — модель начнёт усреднять фото со словами и потеряет сходство.

**Что проверить на готовом ролике,** прежде чем публиковать:

1. Рот закрыт все 10 секунд, речи нет.
2. Лицо читается как Джавохир.
3. Камера не двинулась ни на пиксель.
4. В кадре нет ни одного символа текста.
5. Предмет лежит на столе к 08.9 и ничего не висит в воздухе.
