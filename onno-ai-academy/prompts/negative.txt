# negative.txt — «Один предмет» · Онно AI Academy · v2.0
# THE house negative list. Single source of truth. Nobody retypes this anywhere.
#
# HOW IT IS USED
#   seedance_2_5 on ONNO exposes no negative_prompt field, so this list rides as a
#   trailing block inside params.prompt. TEMPLATE.md §5 defines the transform:
#     1. drop every line whose first non-space character is '#'
#     2. drop empty lines
#     3. join the rest with a single space
#     4. collapse whitespace, strip the ends
#   The result fills the {{NEGATIVE}} slot after "NEGATIVE — ". The day's optional
#   {{NEGATIVE_TODAY}} is appended after it, from the topic block, already ending in ';'.
#   The '#' labels below never reach the model; the ';' category terminators do.
#
# HOW IT IS ORDERED AND HOW LONG IT MAY BE
#   By threat, not by theme. Category 01 is the failure that would most damage the
#   brand; category 12 is cosmetic. Earlier categories carry more weight, and the whole
#   list sits at the tail of a long prompt where attention is weakest — so length is a
#   real cost, not a free safety margin. BUDGET: 780-820 words flattened (v2.0 measures
#   798 words / 5668 chars), about a third of the assembled prompt. v2.0 cut ~460 words
#   that protected nothing current or that fought the positive prompt. If a new token is
#   added, an old one comes out.
#
# HOW IT IS MAINTAINED
#   Every token here must be traceable to a positive clause in TEMPLATE.md §2 that it
#   protects, or to a failure that actually occurred. A token protecting nothing
#   current gets deleted. Prompt text, timeline, this file and the parameter block are
#   ONE versioned unit: change one, re-derive all four.
#
#   Never ban something the format asks for. The hover, the volumetric beam, the dust
#   in it, the grain, the deep blacks, the chiaroscuro, the stone-room tone and the
#   shallow focus are WANTED and are deliberately absent from every category below.
#
# Items inside a category are paraphrase clusters, named both semantically and
# geometrically ("mouth opening" AND "lips parting"), and include wrong OUTCOMES of
# actions we did ask for, not only forbidden objects.
