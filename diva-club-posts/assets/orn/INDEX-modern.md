# Modern accent marks — index

Minimal, frameless register. Black-on-transparent, used as CSS `mask` images
(`background` supplies the colour — gold or maroon, per post). Hairline
weight throughout (stroke-width 1.8 on the 300-unit marks), geometry computed
exactly (real arc, evenly-spaced-by-angle rays, centred cross).

| File | viewBox | Intended use | Recommended on-canvas size |
|---|---|---|---|
| `mark-arc.svg` | `0 0 300 300` | A single open half-circle swoosh — a quiet standalone accent beside a headline, a name, or tucked at a portrait's edge. | 90–110px |
| `mark-rule-dot.svg` | `0 0 600 16` | A hairline rule to sit under a kicker, name, or date line; the off-centre dot reads as an anchor point, not a bullet. | 220–320px wide (height follows the 600:16 aspect, ≈ 6–8px) |
| `mark-plus.svg` | `0 0 300 300` | A small precise cross — beside a short label, or as a divider glyph between two words/lines. | 34–40px. Below ~30px it reads as a stray speck — verified against the proof sheet, do not go smaller. |
| `mark-sunburst.svg` | `0 0 300 300` | A minimal 12-ray burst — a small "moment" marker near a date/time or beside a short phrase. | 70–90px |
| `mark-bracket.svg` | `0 0 300 300` | Two crop-mark corner brackets, diagonally opposed in one file — place at the opposite corners of a text block, scaling the SVG's own box to match that block. | ~140–200px to frame a short 2–3 word phrase; ~300–420px to frame a full headline block on a 1080px-wide canvas. |

**Restraint rule:** no more than two of these marks on any single post — most
posts should carry exactly one. If a second appears, it must read as clearly
secondary (smaller and/or quieter) so the eye still lands on one thing, not two.
