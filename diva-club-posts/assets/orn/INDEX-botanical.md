# Botanical ornament set

Black shapes on transparent, hand-drawn bezier line art, used as CSS masks
(`-webkit-mask: url(...)`) — apply colour with `background`. Stroke weight
1.6 on all linework, matching `corner.svg` / `flourish.svg`.

| File | viewBox | Intended use | Recommended on-canvas size |
|---|---|---|---|
| `rose-spray.svg` | `0 0 200 320` | Single-stem rose with a side bud and a few leaves — a corner accent or a mark beside a title. Asymmetric. | ~150×240 px |
| `leaf-divider.svg` | `0 0 640 48` | Horizontal divider — a hairline-tapered leafy vine with a small blossom at centre — under a title or above the date/location line. | ~480×36 px |
| `bloom-corner.svg` | `0 0 300 300` | Corner spray with a small blossom near the apex, drawn for the TOP-LEFT corner. Rotate 90/180/270° (or flip) in CSS for the other three corners. | ~220×220 px |
| `floral-arch-top.svg` | `0 0 420 150` | Symmetrical crown of blossom and leaves — centred above a title or over an arch. | ~360×129 px |
