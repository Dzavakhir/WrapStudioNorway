# 150 ta ChatGPT kod — PDF gayd

A romantic-classic (burgundy & cream) A4 PDF guide, written in Uzbek, with 150 slash-codes
(`/golden_hour`, `/polaroid`, `/red_pop`, …) that readers send to ChatGPT to edit their photos.
Every code is illustrated with the result applied to the guide's model photo, so the reader sees the
outcome before trying it. The finished book is `dist/150-ta-ChatGPT-kod-gayd.pdf`.

## Structure

| Path | What it is |
|---|---|
| `source/` | model portrait (`original.jpg`), the 4:5 working crop, landmark metadata and segmentation masks |
| `codes.json` | the 150 codes: category, Uzbek title/description, English ChatGPT prompt, designer hints (generated by `tools/codes_src.py`) |
| `effects/lib.py` | shared image toolkit (tone/colour, blend modes, glow, masks, textures, frames, typography) |
| `effects/g01.py … g30.py` | the 30 designer groups, 5 codes each, registered with `@effect('code')` |
| `render.py` | renders every code to `renders/NNN_code.jpg` (1152×1440) plus contact sheets in `previews/` |
| `book/build.py` | assembles the A4 HTML book (cover, intro, contents, 15 sections, master prompt, closing) |
| `book/print.js` | prints the HTML to PDF with Chromium (Playwright) and reports layout overflows |
| `book/fonts/` | Playfair Display, Lato, Cormorant Garamond (woff2 for the book, ttf for effect typography) |

## Rebuild

```bash
pip install pillow numpy opencv-python-headless scipy mediapipe   # once
python3 tools/prepare.py          # only if the source photo changes: crop + masks
python3 render.py all             # 150 renders (about 3–4 minutes on 4 cores)
python3 book/build.py             # book/index.html + book/img/
NODE_PATH=/opt/node22/lib/node_modules node book/print.js   # -> dist/150-ta-ChatGPT-kod-gayd.pdf
python3 tools/pdf_preview.py dist/150-ta-ChatGPT-kod-gayd.pdf 1 2 3   # rasterise pages for a visual check
```

`python3 render.py g07` renders one group and writes `previews/g07.jpg`; `python3 tools/brief.py g07`
prints that group's brief (codes, prompts, hints).
